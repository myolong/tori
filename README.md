# 토리 숲

할 일을 끝낼 때마다 도토리 요정 토리가 물방울을 먹고 자라고, 다 자란 토리 나무를 심어 나만의 숲을 만드는 습관 앱입니다.

## 지금 버전 (1차)

- 로그인 없이 휴대폰 브라우저(localStorage)에 저장. 홈 화면에 추가하면 앱처럼 열리고 오프라인에서도 열림
- 할 일 추가·완료·삭제, 매일 반복 할 일
- 물방울 성장 5단계(0/10/30/60/100), 하루 최대 10개, 하루 3개 완료 시 별사탕
- 이틀 넘게 안 오면 토리가 낮잠(벌칙 없음)
- 다 자란 토리를 '내 숲'에 심기, 1·3·6·10·15그루마다 숲에 새 요소
- 다음 단계: 클링 AI로 만든 3D 그림 교체, 별사탕 상점, 하루 일기 카드, 알림

## 구조

- `public/`: 앱 파일 (index.html, sw.js, manifest, 아이콘)
- `build.mjs`: `public/`을 `dist/`로 복사하고 서비스워커 버전을 갱신 (외부 패키지 없음)
- `wrangler.jsonc`: Cloudflare Workers가 `dist/`를 정적 사이트로 올림

## Cloudflare 배포 설정

빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy` (기본값 그대로).
